# Паспорт Лавки

Профиль правил: base

## Что делает сервер

Перечислите доступные действия и изменяемые данные.
Сервер предоставляет MCP-инструменты для чтения каталога, товара, баланса и состояния заказа, а также для создания, отмены и выдачи заказа.

## Границы

Какие пользователи существуют? Есть ли проверка личности? Какие действия клиенту обещать нельзя?
Сервер работает только с пользователями из учебной базы и не проверяет личность вызывающего. Клиенту нельзя обещать создание пользователя, пополнение баланса, оплату деньгами, доставку или изменение каталога. Ожидаемые отказы возвращаются кодами ошибок, а не исключениями Python.

## Путь запроса

Клиент → имя инструмента → функция обработчика → правило, если нужно → метод хранения → ответ.
client.py → get_product в build_mcp_server() из src/mcp_adapter.py → read_handlers.get_product() → Storage.get_product() → success(...) или failure("PRODUCT_NOT_FOUND", ...).
